# Programa para calcular el total de una compra

Este proyecto contiene un programa desarrollado en Python que resuelve un
problema sencillo de la vida real.

El programa solicita el precio de un producto y la cantidad que lleva el
cliente. Posteriormente, utiliza una función llamada `calcular_total` para
multiplicar ambos valores y mostrar el total que debe pagar el cliente.
